# RAG evaluation project

**Open [PLAN.md](./PLAN.md). That's the only file you need.**

---

## What's here

```
rag-eval-practice/
├── PLAN.md          ← open this every day; update the CURRENT line
├── EXERCISE-01.md   ← detailed method for Days 3-5, the gold set
├── corpus/          ← your 25-30 doc pages + INDEX.md (Day 1)
├── gold/            ← your gold question set (Days 3-5)
│   └── gold-set-template.md   worked example, match its shape
├── src/             ← code you write (Days 2, 7, 9-11)
├── results/         ← measured numbers per variant (Days 8, 10)
└── notes/           ← hand math, failure diagnoses, findings
    └── findings.md  reflection prompts for Exercise 1
```

Empty folders are correct. You fill them.

## The one rule

Every line in `src/` is one you wrote and can explain tomorrow. If that stops
being true, stop and go back.

`groundtruth/` is a sealed reference implementation. Open it only after you've
attempted the same thing yourself and have been stuck for 30+ minutes.
